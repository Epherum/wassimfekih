# Wassim Fekih Portfolio

Personal portfolio site built with Next.js.

## Setup
```bash
npm install
```

## Environment Variables
None required for local development.

## Run
```bash
npm run dev
# open http://localhost:3000
```

## Backup & Restore (resetting your PC)
Back up before wiping:
- Any local changes in `pages/`, `public/`, or `styles/` you want to keep.

Restore steps:
1. Clone the repo and run `npm install`.
2. `npm run dev` to start locally.
